React Cart Application Assignment
Create a React-based cart application to manage products in a shopping cart.

Objective & Requirements
Objective
Develop a shopping cart application using useContext and useReducer hooks for state management. The application should enable users to add, remove, and adjust the quantity of products in the cart.
Environment Setup	Use Node.js version 16. Follow the nvm installation guide for setup.
Features	
Navbar displaying the total count of items in the cart.
Product list with options to adjust quantity and remove items.
"Clear Cart" button to remove all items.
Total cart amount display.
Class Names & IDs	
Main app container ID: "main".
Increment button ID: "increment-btn-`id`".
Decrement button ID: "decrement-btn-`id`".
Cart items list ID: "cart-items-list".
Clear Cart button ID: "clear-all-cart".
Total amount ID: "cart-total-amount".
Item price ID: "cart-item-price-`id`".
Item amount ID: "cart-amount-`id`".
Navbar cart item count ID: "nav-cart-item-count".
Some Functionalities which are required
The main page should include:

A navbar with a cart logo and item count.
A list of cart items including product name, price, and quantity with buttons to adjust the quantity.
A "Clear Cart" button to remove all items.
A display of the total cart amount.
For an empty cart, display a message "Cart is currently empty".
